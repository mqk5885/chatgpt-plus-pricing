## 12 月起，额度的计算方式要变

OpenAI 帮助中心 2026 年 11 月 2 日更新了一条规则：**自 12 月起，Plus、Pro 和 Business 的用量额度由 ChatGPT 与 Codex 共用，按 token 计量。** 模型越强、任务越复杂，消耗越多；Instant 对话不计入额度。合并后的剩余用量和重置时间在"设置 → 用量"里查看，用完之后可以等重置、升级套餐，或者单独购买额度。

具体生效日期和各档额度官方还没公布，价格也没有变。这条对重度使用 Codex 的人影响最大：以前 Work 和 Codex 各有一份额度，合并后是一份总量，两边一起消耗。

Plus 原本的限制本来就不写具体数字，官方措辞是"Plus 订阅可能包含消息上限等用量限制，尤其在需求高峰时，这些限制会随系统状况变化"。12 月之后，至少剩余量能在设置里看到。

## $20 买到什么，买不到什么

官方列出的 Plus 权益：

- 高流量时段优先访问，减少排队
- 比 Free 更高的模型用量与更多模型选择
- 高级推理，用于编程、规划、多步分析
- 更快的响应速度
- 语音对话、图像生成、文件上传与分析、Deep Research（可用地区）

三条限制同样写在官方文档里，买之前值得看清楚：

1. **用量上限不公开具体数字**，只在帮助中心用文字描述，高峰期可能收紧。
2. **API 用量不含在 Plus 里**，单独计费。想在应用之外调用模型，要另开 API 账号。
3. **模型清单会变**，rollout 期间不同账号看到的选项可能不一样，以你自己的 model picker 为准。

另外，Plus 订阅可以授权参与工具使用你包含的额度（Sign in with ChatGPT），连接工具不产生独立额度，也不等于 API 计费，但账号凭证不能共享或转售。

如果你主要担心的是"一个月 $20 够不够用"，判断标准很实际：日常问答和写作，Plus 基本碰不到限制；天天跑长任务的 Codex 和 deep research，才会撞到额度墙。

## 谁不该买 Plus

这部分比推荐更重要，因为买错了退起来要等。

**只做文字聊天的人，Free 就够。** Free 的文字聊天不限量，Plus 多出来的是模型和工具。如果你的用法是问问题、改文案、翻译，多花 $20 换不到体验上的差别。

**只用上传、图片、语音、记忆的人，选 Go $8。** Go 在这几项上的额度都比 Free 高，代价是仍然显示广告，也拿不到 Plus 的推理模型。

**每周把 Codex 和 Work 额度用满的人，直接看 Pro 100。** Plus 的额度对高频代码任务来说是瓶颈，Pro 100 提供更长的会话和每月 API 额度。Pro 200 和 Pro 500 是给用量继续往上走的人准备的，Pro 500 的 Ultrafast 消耗额度是标准速率的 8 倍，用得快也正常。

**团队采购别看个人档。** 2 人以上、需要共享工作区和统一账单，Business Standard 年付 $20/席，和 Plus 同价但多了管理功能；需要 5 倍用量且不想被五小时限制卡住的，看 Business Premium。

## 拿 API 价格比一下：$20 到底买到多少次回答

gpt-6.1-sol 的标准价是每百万输入 token $2.00、每百万输出 token $10.00。一次"输入 1,000 token + 输出 500 token"的回答，成本 $0.007。$20 大约能买 **2,857 次**这样的回答，折合每天约 **95 次**。

单看数字，API 比订阅便宜。但 API 拿不到 ChatGPT 应用本身：没有记忆、没有图片工具、没有语音模式，长对话每一轮都要重发全部历史，越聊越贵。真正需要把模型嵌进自己程序里的人选 API，日常使用的人选订阅，这两笔钱不是互相替代的关系。

## 下单前要确认的几件事

**税。** 美国和加拿大标价不含税，结账时另加；欧盟、英国、日本等地区的 App Store 标价已含当地增值税。€22.99 在德国、西班牙是含税价，$19.99 在美国不含税，直接比数字会失真。

**渠道。** App Store 订阅由 Apple 管理，退款和退订走苹果；官网订阅走银行卡，管理入口在 chatgpt.com → 头像 → Settings → Account。如果被扣费但仍显示 Free，先确认登录的是订阅对应的账号——用 Apple"隐藏我的电子邮件"注册的，账号可能是 `@privaterelay.appleid.com`，需要用同一个 Apple 账号"Continue with Apple"登录，再在 App 的 Settings > Restore purchases 同步。

**退款。** 申请获批后通常 5–10 个工作日处理完成，提交时必须登录订阅对应的 ChatGPT 账号，收据邮箱可能和账号邮箱不是同一个。

**低价区的代价。** 菲律宾区按汇率算确实比美区便宜约 20%，但跨区订阅要面对条款、付款方式和风控三件事，不推荐拼车和代充成品号，账号归属和质保都不在自己手上。
